# 株式会社あかがね工業 — サンプルサイト

新居浜市のプラント仮設足場・建築足場の会社をイメージした、**コーポレートサイトのデモ・サンプル**です。
AI（Claude Code）を使った Web 制作の研修で、「このくらいのサイトが、どのくらいの時間でできるか」を見せるために作りました。

> ⚠️ **お断り**
> 本サイトは株式会社あかがね工業の公式サイトではなく、同社とは関係ありません。
> 掲載している数値・施工事例・連絡先・会社情報は、すべて架空のサンプルです。
> 実在の企業名を題材にしていますが、同社の情報（住所・電話番号・人物・写真）は一切使っていません。

## 見る

ビルド不要。`index.html` をブラウザで開くだけです。

```
index.html
assets/
  css/style.css   デザイン
  js/main.js      メニュー・スクロール表示・数字のカウント・フォーム（送信はしない）
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages → Branch を `main` / `(root)` にします。
検索エンジンに載らないよう、`<meta name="robots" content="noindex">` を入れてあります。

## デザインの考え方

- **あかがね ＝ 銅**。新居浜が銅とともに育った町であることから、銅色（`#B8622B`）を差し色に
- **足場のグリッド**をモチーフに、ヒーローの背景とロゴマークを作成
- 見出しは明朝体（Shippori Mincho B1）、本文はゴシック（Noto Sans JP）。職人の会社らしい落ち着きを出す
- 写真は使わない（サンプルのため）。施工事例は図案で代用
- スマホ対応・キーボード操作・動きを減らす設定（prefers-reduced-motion）に対応

## 構成

| セクション | 内容 |
|---|---|
| ヒーロー | キャッチコピー「止めない現場を、足場から支える。」 |
| 数字 | 創業年数・有資格者・年間施工件数・無災害日数（サンプル値） |
| 事業内容 | プラント仮設足場／定修・メンテナンス足場／建築・改修足場／特殊足場 |
| 安全への取り組み | KY 活動・有資格者点検・段取りの見える化 |
| 施工の流れ | お問い合わせ → 現地調査 → 計画・見積 → 組立 → 点検・解体 |
| 施工事例 | 3件（架空） |
| 会社概要 | サンプル値 |
| 採用情報 | 未経験歓迎・資格取得支援 |
| お問い合わせ | フォーム（送信されない）・電話番号はダミー |
